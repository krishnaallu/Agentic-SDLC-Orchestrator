# Requirement Traceability

This matrix records repository evidence. Generated proposal documents are not equivalent to a deployed URL-shortener implementation.

| Requirement | Evidence | Status / boundary |
|---|---|---|
| Clear package boundaries | `api`, `application`, `agent`, `domain`, `persistence`, `configuration`, `workflow`, and `security` packages; [architecture.md](architecture.md) | Implemented for the orchestrator. URL-shortener packages are generated proposal files, not live application code. |
| Authenticated, role/scope-based approvals | [SecurityConfiguration.java](../src/main/java/com/example/orchestrator/configuration/SecurityConfiguration.java), [OrchestrationController.java](../src/main/java/com/example/orchestrator/api/OrchestrationController.java), [AgenticOrchestratorPostgresIT.java](../src/test/java/com/example/orchestrator/AgenticOrchestratorPostgresIT.java) | Implemented with JWT scopes; audit actor comes from token subject. Requires a configured OIDC issuer. |
| API request/rate limits | [ApiRequestGuardFilter.java](../src/main/java/com/example/orchestrator/security/ApiRequestGuardFilter.java), [ApiRequestGuardFilterTests.java](../src/test/java/com/example/orchestrator/security/ApiRequestGuardFilterTests.java) | Implemented in-process with fixed-window limits and body/content-length checks. Not distributed across replicas. Generated service proposal has Redis rate limiting. |
| Destination SSRF checks | [TemplateTaskExecutionAgent.java](../src/main/java/com/example/orchestrator/agent/TemplateTaskExecutionAgent.java), [ProposalValidator.java](../src/main/java/com/example/orchestrator/workflow/ProposalValidator.java) | Present as generated service source/static assertions. Needs DNS-rebinding-resistant policy review and runtime service tests before deployment. |
| Bounded read-only brownfield snapshot and revision | [CodebaseSnapshotNormalizer.java](../src/main/java/com/example/orchestrator/application/CodebaseSnapshotNormalizer.java), [CreateRunRequest.java](../src/main/java/com/example/orchestrator/api/CreateRunRequest.java), [CodebaseSnapshotNormalizerTests.java](../src/test/java/com/example/orchestrator/application/CodebaseSnapshotNormalizerTests.java) | Implemented for caller-supplied files, max 25 files/120 KB, path checks and secret-like assignment redaction. Revision is caller-declared, not verified against Git. |
| Impacted code and compatibility/regression checks | Brownfield artifacts emitted by [TemplateTaskExecutionAgent.java](../src/main/java/com/example/orchestrator/agent/TemplateTaskExecutionAgent.java) | Candidate file inventory and checklist generated. Not semantic dependency analysis or proof of compatibility. |
| Isolated execution, limits, cleanup, evidence | [IsolatedProjectValidator.java](../src/main/java/com/example/orchestrator/workflow/IsolatedProjectValidator.java), [OrchestrationActivityService.java](../src/main/java/com/example/orchestrator/workflow/OrchestrationActivityService.java), [AgenticOrchestratorApplicationTests.java](../src/test/java/com/example/orchestrator/AgenticOrchestratorApplicationTests.java) | Greenfield and Brownfield generated builds/tests passed in a network-disabled disposable Docker container with required validation enabled. Orchestrator tests mock-disable Docker by default; use the runbook command to execute scenario sandboxes. No source is applied to a service checkout. |
| Integration/security/deployment/final workflow gates | [DeterministicPlanningAgent.java](../src/main/java/com/example/orchestrator/agent/DeterministicPlanningAgent.java), [OrchestrationService.java](../src/main/java/com/example/orchestrator/application/OrchestrationService.java) | Graph nodes and dependencies exist. Security/deployment review artifacts still require human review; dynamic URL-shortener scanning is not an automated stage. |
| Real PostgreSQL/API/security/concurrency tests | [AgenticOrchestratorPostgresIT.java](../src/test/java/com/example/orchestrator/AgenticOrchestratorPostgresIT.java), [AgenticOrchestratorApplicationTests.java](../src/test/java/com/example/orchestrator/AgenticOrchestratorApplicationTests.java) | PostgreSQL Testcontainers covers migrations, approval scopes/audit identity, and concurrent run creation. Generated URL-shortener API behavior still needs its own executable test project. |
| Dependency scanning | [verify.yml](../.github/workflows/verify.yml) uses the OSV-Scanner reusable workflow | Local OSV-Scanner v2.6.0 scan of `pom.xml` reported no issues after patching Jackson 2/3 and Tomcat. CI fails on reported vulnerabilities; lookup uses online OSV/deps.dev APIs, not an NVD corpus download. |
| Metrics, runbook, deployment guidance | [runbook.md](runbook.md), [README.md](../README.md), Actuator/Prometheus configuration | Guidance and metrics exist. Production SLOs, alerting, backup-restore evidence, and production Temporal deployment remain operator responsibilities. |
